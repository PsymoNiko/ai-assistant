# src/backend

This directory contains backend services for the ai-assistant project.

Suggested subfolders:
- api/        — REST/GraphQL endpoints
- core/       — session management, prompt orchestration, plugins orchestration
- adapters/   — LLM provider adapters (OpenAI, Anthropic, local models)
- storage/    — database models and migrations
- services/   — retrieval, embedding, memory modules

Start here when implementing backend components.
