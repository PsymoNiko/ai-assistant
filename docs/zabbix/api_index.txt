62073:Overview The Zabbix API allows you to programmatically retrieve and modify configuration of Zabbix and provides access to
62078:The Zabbix API is an HTTP-based API, and it is shipped as a part of the web frontend. It uses the JSON-RPC 2.0 protocol, which
62080:• The API consists of a set of separate methods.
62081:• Requests and responses between the clients and the API are encoded using the JSON format.
62082:For more information about the protocol and JSON, see the JSON-RPC 2.0 specification and the JSON format homepage.
62083:For more information about integrating Zabbix functionality into your Python applications, see Python library for Zabbix.
62090:The API consists of a number of methods that are nominally grouped into separate APIs. Each of the methods performs
62092:one specific task. For example, the host.create method belongs to the host API and is used to create new hosts. Historically,
62093:APIs are sometimes referred to as ”classes”.
62094:Most APIs contain at least four methods: get, create, update and delete for retrieving, creating, updating and deleting data
62095:respectively, but some APIs may provide a totally different set of methods.
62098:Once you have set up the frontend, you can use remote HTTP requests to call the API. To do that, you
